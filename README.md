## ✦ O que é

Um blog pessoal de exploração urbana. Escolho um lugar de São Paulo, vou, fotografo e escrevo — e o site transforma isso num artigo bonito, no capricho de uma reportagem de jornal. Com o tempo, o mapa vai se enchendo de pontos e o diário vai virando um retrato da cidade, uma parada por vez.

## ✦ Por dentro

- 📰 **Explorações em formato de jornal** — texto em colunas, foto no canto, imagem grande abrindo a página. Cada exploração tem seu próprio link pra compartilhar.
- 🗺️ **Mapa interativo de São Paulo** — só a capital, mostrando exatamente os lugares que já visitei, ponto por ponto.
- 📍 **Lugares & bairros** — cada lugar reúne todas as minhas visitas; os bairros se organizam sozinhos conforme eu exploro.
- 📖 **Diário** — tudo em ordem, do mais recente ao começo de tudo, com rolagem infinita.
- 🔎 **Busca** — encontro lugares, explorações e bairros na hora.
- 🌗 **Tema claro e escuro** — pergaminho de dia, tinta de noite.
- 🛠️ **Painel do autor** — cadastro dos lugares, escrita e publicação das explorações, e a página “Sobre mim” — tudo editável por mim, sem tocar em código.

## ✦ Como escrevo uma exploração

1. Escolho o lugar (já cadastrado) e a data.
2. Subo as fotos (até 20) e **organizo a ordem** — a primeira vira a capa.
3. Escrevo o relato solto e mando **organizar** — o texto ganha ritmo de reportagem.
4. Confiro o preview no layout de jornal e **publico**. Pronto: link próprio, no diário e no mapa.

> As fotos são gerenciadas por mim a qualquer momento: reordenar ou apagar reflete na hora na página publicada.

## ✦ Rodar no meu PC

Requisitos: Node 18.18+.

```bash
npm install     # instala tudo
npm run dev      # abre em http://localhost:3000
```

Outros comandos úteis:

```bash
npm run build     # versão de produção
npm run start     # serve a versão de produção
npm run lint      # checagem de código
```

O painel fica em **`/admin`** (senha padrão de desenvolvimento: `turistando`).
